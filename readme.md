# PtychoX: differentiable ptychography powered by CUDA!
PtychoX is an open-source library for CUDA-accelerated differentiable phase retrieval solver of ptychographic imaging family with MATLAB bindings. It is inspired by a Chinese paper "CUDA-Accelerated Fourier Ptychographic Microscopy (Invited)" [[1](https://researching.cn/ArticlePdf/m00002/2025/62/15/1511001.pdf)]
