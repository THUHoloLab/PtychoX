PtychoX is an open-source library that provides CUDA-accelerated, differentiable phase-retrieval solvers for the ptychographic imaging family, with native MATLAB bindings. The project is inspired by the Chinese paper “CUDA-Accelerated Fourier Ptychographic Microscopy (Invited)” [[1](https://researching.cn/ArticlePdf/m00002/2025/62/15/1511001.pdf)]. Building upon this foundation, PtychoX extends the original framework to **four distinct ptychographic applications**, each implemented with end-to-end differentiable formulations.

## How to Use

This section demonstrates how to use **PtychoX** for **near-field (Fresnel) ptychography** using a fully differentiable, GPU-accelerated pipeline.  
The workflow closely follows the physical forward model and solves the inverse problem via automatic differentiation and gradient-based optimization.

---

### 1. Problem Formulation

In near-field ptychography, the object is illuminated by a localized probe and measured after free-space propagation.  
For the *k-th* scan position \(\mathbf{r}_k\), the forward model can be written as

\[
\begin{aligned}
\psi_k(\mathbf{r}) &= O(\mathbf{r} + \mathbf{r}_k)\, P(\mathbf{r}), \\
\Psi_k(\mathbf{u}) &= \mathcal{F}\{\psi_k(\mathbf{r})\}, \\
\tilde{\Psi}_k(\mathbf{u}) &= \Psi_k(\mathbf{u}) \cdot H(\mathbf{u}), \\
I_k(\mathbf{r}) &= \left| \mathcal{F}^{-1}\{\tilde{\Psi}_k(\mathbf{u})\} \right|,
\end{aligned}
\]

where:

- \(O(\mathbf{r})\) is the complex object,
- \(P(\mathbf{r})\) is the probe (illumination),
- \(H(\mathbf{u}) = \exp\!\left(i k z \sqrt{1 - \lambda^2 |\mathbf{u}|^2}\right)\)  
  is the **near-field (angular spectrum) propagation kernel**,
- \(\mathcal{F}\) denotes the 2D Fourier transform.

The inverse problem aims to recover \(O\) and \(P\) from intensity-only measurements \(\{I_k\}\).

---

1. Constructing a **complex object**

2. Defining a **probe function** using an angular spectrum propagation model.
